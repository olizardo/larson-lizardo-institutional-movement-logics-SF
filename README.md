# Replication Package

**Paper:** Larson, Jeff, and Omar Lizardo. 2019. "Institutional Movement Logics and the Changing Shape of the US Social Movement Field, 1960–1995." *Social Forces* 97(4): 1389–1422. doi:[10.1093/sf/soy122](https://doi.org/10.1093/sf/soy122)

This repository reproduces every table and figure reported in the final published version of the paper (archive: `larson-lizardo-institutional-movement-logics-SF/SF-Final/SOY122 (corrected).pdf`). The entire pipeline — including the original Stata recodes — has been ported to R; no Stata dependency remains.

## How to run

```sh
cd <this folder>
Rscript run-all.R
```

Run order: `00` → `07`. Total runtime is a few minutes; the only heavy step is the year-level MCA (23,613 events).

Requirements: R (tested on 4.5.3) with `foreign`, `haven`, `dplyr`, `tidyr`, `FactoMineR`, `factoextra`, `cluster`, `ggplot2`.

## Source data

Git tracks only the code and documentation. The raw dataset (`Full Data 2.2.dta`, 59 MB) and the archived project files live in the extracted project archive folder `larson-lizardo-institutional-movement-logics-SF/` next to the scripts (originally downloaded as a Google Drive zip export); that folder must be present before running. Everything under `data-derived/` and `output/` is generated by the pipeline.

## What the pipeline does

The original analysis chain was: raw DCA event data (`Full Data 2.2.dta`) → Stata recodes (`do/period-data-four-chunks.do`, `do/ca-data-recode-v2.2.do`, `do/supplementary.do`) → event × ITT indicator files per period → MCA → divisive hierarchical clustering of the "yes" ITT modalities → PCA-style plots and supplementary-variable rankings.

The R port reproduces this chain end-to-end:

| Script | Original source | Produces |
|---|---|---|

| `01_prep-supplementary-vars.R` | `do/supplementary.do` + `do/ca-data-recode-v2.2.do` | `data-derived/Supplementary-Vars-2.2.dta`, `data-derived/ca-data-period{1-4}-{0,1,2,5,7,10}p.dta` |

## Validation

`07_validate.R` verifies that the R pipeline reproduces the archived analysis files that generated the published results:

- `Full Data 2.2.dta` was confirmed to be the exact source of the shipped intermediates (every ITT indicator matches on all matched events; row counts identical).
- The regenerated `ca-data-*-1p.dta` files are compared with the archived versions (rows, column names/order, values).
- The regenerated `top.sups.period{1-4}.csv` rankings are compared with the archived `csv/` versions.

Because the clustering (DIANA + complete linkage) and MCA are deterministic, identical inputs give identical outputs; the validation script confirms this empirically.

## Notes and caveats

- The Stata `.do` files are kept in the archive folder for provenance. The archived `.dta` intermediates predate the final `.do` files, so the port treats the **archived analysis files** as ground truth for the data step and verifies against them (`07_validate.R` reports ALL CHECKS PASSED: identical rows, column names/order, and values).
- The supplementary variable set here adds back the **police-presence** variable (`POLICE_PRESENCE`, renamed to avoid clashing with the identically named police-target ITT indicator) plus `EVENTSIZE` and `REGION` for all periods. The published Table 3 contains police-presence and region categories, which can only come from a run in which those variables were among the supplementary projections; they are passive in the MCA, so adding them leaves the figures and cluster solutions unchanged.
- Consequently, Table 3 is reproduced in the published configuration. The regenerated top-25 rankings overlap 21-24 of 25 categories per logic with the archived draft CSVs (`csv/top.sups.period{1-4}.csv`, themselves an intermediate without police categories); the published-form top-10 is written to `output/tables/table3-top10-sups.csv` (e.g., the Civil rights column for 1960-1965 matches the published table in order, 10/10).
- In the published Table 1, the *School obstructionist* panel's Targets row reads "Civil Disobedience | Strike | Sit-in", which appears to be a cell-shift typesetting artifact (those are tactics). `06_curated-tables.R` transcribes the table **as printed**; the note inside the script flags the anomaly.
- Threshold suffixes mirror the original convention: `-1p` = keep ITTs with prevalence >= .01 (the threshold used for all published results); `0p/2p/5p/7p/10p` are the sensitivity variants analyzed in `R/sensitivity-p{1-4}.r` (not part of the published tables/figures).
- Figure 1 is a schematic diagram (no data content) and is not regenerated.
